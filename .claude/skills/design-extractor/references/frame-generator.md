# Frame Generator – Extracting Pages/Views to Figma

## What this does

Reads every route/page in the app and generates Figma frames with correct
layout, component placement and Auto Layout — automatically.

---

## Step 1: Identify all routes/pages

### Next.js (App Router)
```
app/
  page.tsx              → "Home"
  about/page.tsx        → "About"
  dashboard/page.tsx    → "Dashboard"
  profile/page.tsx      → "Profile"
  settings/page.tsx     → "Settings"
```

### Next.js (Pages Router)
```
pages/
  index.tsx             → "Home"
  about.tsx             → "About"
  dashboard.tsx         → "Dashboard"
```

### React (React Router)
Look in: `App.tsx`, `router.tsx`, `routes.tsx`
```tsx
<Route path="/" element={<Home />} />
<Route path="/dashboard" element={<Dashboard />} />
```

### SwiftUI
Look for files with `View` suffix, `ContentView.swift`, `NavigationView`

### HTML/CSS
All `.html` files in root or `pages/` folder

---

## Step 2: Analyze layout per page

For each page file, identify:

### Hierarchy (what exists on the page)
```
1. Navbar/Header     → nav component at the top?
2. Hero/Banner       → large section with heading + text + button?
3. Main content      → cards, lists, forms, tables?
4. Sidebar           → aside/sidebar element?
5. Footer            → footer component?
```

### Layout mapping
```
CSS/Tailwind signal       →    Figma Auto Layout
──────────────────────────────────────────────────
flex flex-col             →    Vertical, gap=X
flex flex-row / flex      →    Horizontal, gap=X
grid grid-cols-3          →    Horizontal, 3 items, gap=X
space-y-4                 →    Vertical, gap=16
p-6                       →    Padding 24px all sides
px-4 py-2                 →    Padding H:16 V:8
w-full                    →    Fill container
max-w-7xl mx-auto         →    Fixed width 1280px, centered
```

## Step 3: Build the combined script

```javascript
// ============================================
// DESIGN IMPORT – [Project Name]
// Generated by Claude Code – [Date]
// Run in: Figma → Plugins → Development → Open Console
// Run it in a fresh, empty Figma file — running it twice duplicates every page and style.
// ============================================

// ---- TOKENS ----
// Every color used anywhere below must exist here — including one-off hardcoded
// values found in components (e.g. badge backgrounds). Never put hex literals in
// components[] or pages[]; reference tokens.colors instead (Rules 2 and 3).
const tokens = {
  colors: {
    "primary":        "#3B82F6",
    "primary-hover":  "#2563EB",
    "primary-subtle": "#EFF6FF",
    "background":     "#FFFFFF",
    "surface":        "#F9FAFB",
    "text-primary":   "#111827",
    "text-secondary": "#6B7280",
    "text-inverse":   "#FFFFFF",
    "border":         "#E5E7EB",
    "error":          "#EF4444",
    "error-subtle":   "#FEF2F2",
    "success":        "#10B981",
    "success-subtle": "#F0FDF4",
    "warning":        "#F59E0B"
  },
  typography: {
    "heading-xl":  { family: "Inter", size: 36, weight: 700, lineHeight: 1.2 },
    "heading-lg":  { family: "Inter", size: 30, weight: 700, lineHeight: 1.25 },
    "heading-md":  { family: "Inter", size: 24, weight: 600, lineHeight: 1.3 },
    "body-base":   { family: "Inter", size: 16, weight: 400, lineHeight: 1.5 },
    "body-sm":     { family: "Inter", size: 14, weight: 400, lineHeight: 1.5 },
    "label":       { family: "Inter", size: 14, weight: 500, lineHeight: 1.4 },
    "button":      { family: "Inter", size: 14, weight: 600, lineHeight: 1 },
    "caption":     { family: "Inter", size: 12, weight: 500, lineHeight: 1.4 }
  },
  // box-shadow → DROP_SHADOW. Use a color token key when the shadow's rgb matches one.
  shadows: {
    "card": { x: 0, y: 1, blur: 3, spread: 0, color: "text-primary", opacity: 0.1 }
  }
};
const C = tokens.colors;

// Repo font → Figma alternatives, tried in order. Inter is always the last resort.
// e.g. "Source Serif 4": ["Lora"]
const FONT_FALLBACKS = {};

const FRAME_SIZES = [
  { label: "Mobile",  width: 390,  height: 844 },
  { label: "Desktop", width: 1440, height: 960 }
];

// ---- HELPERS ----
function solidColor(hex, alpha = 1) {
  if (!hex || hex === "transparent") return [];
  const r = parseInt(hex.slice(1,3), 16) / 255;
  const g = parseInt(hex.slice(3,5), 16) / 255;
  const b = parseInt(hex.slice(5,7), 16) / 255;
  return [{ type: "SOLID", color: { r, g, b }, opacity: alpha }];
}

// Horizontal gradient (left → right)
function hGrad(h1, h2) {
  const c1 = solidColor(h1)[0].color;
  const c2 = solidColor(h2)[0].color;
  return [{
    type: "GRADIENT_LINEAR",
    gradientTransform: [[1, 0, 0], [0, 1, 0]],
    gradientStops: [
      { position: 0, color: { ...c1, a: 1 } },
      { position: 1, color: { ...c2, a: 1 } },
    ],
  }];
}

// Vertical gradient (top → bottom)
function vGrad(h1, h2) {
  const c1 = solidColor(h1)[0].color;
  const c2 = solidColor(h2)[0].color;
  return [{
    type: "GRADIENT_LINEAR",
    gradientTransform: [[0, 1, 0], [-1, 0, 1]],
    gradientStops: [
      { position: 0, color: { ...c1, a: 1 } },
      { position: 1, color: { ...c2, a: 1 } },
    ],
  }];
}

// Shadow token → Figma effects array
function shadow(key) {
  const s = tokens.shadows[key];
  if (!s) return [];
  const { r, g, b } = solidColor(C[s.color] || s.color)[0].color;
  return [{
    type: "DROP_SHADOW", color: { r, g, b, a: s.opacity },
    offset: { x: s.x, y: s.y }, radius: s.blur, spread: s.spread,
    visible: true, blendMode: "NORMAL",
  }];
}

function weightToStyle(w) {
  return { 400:"Regular", 500:"Medium", 600:"Semi Bold", 700:"Bold", 800:"Extra Bold" }[w] || "Regular";
}

function named(node, name) { node.name = name; return node; }

// Create a text node from a typography token (must be called after loadFonts).
// Name text layers that instances will override: named(txt(...), "Label").
function txt(chars, typoKey, hexColor, alpha = 1) {
  const typo = tokens.typography[typoKey] || tokens.typography["body-sm"];
  const n = figma.createText();
  n.fontName = { family: typo.family, style: weightToStyle(typo.weight) };
  n.fontSize = typo.size;
  n.characters = chars;
  n.fills = solidColor(hexColor, alpha);
  n.lineHeight = { unit: "PERCENT", value: typo.lineHeight < 10 ? typo.lineHeight * 100 : typo.lineHeight };
  return n;
}

// Turn a node into an auto-layout frame that hugs its content on both axes
function autoLayout(node, direction, o = {}) {
  node.layoutMode = direction;
  node.primaryAxisSizingMode = "AUTO";
  node.counterAxisSizingMode = "AUTO";
  node.itemSpacing = o.gap || 0;
  node.paddingLeft = node.paddingRight = o.padX || 0;
  node.paddingTop = node.paddingBottom = o.padY || 0;
  node.cornerRadius = o.radius || 0;
  node.fills = solidColor(o.fill);
  if (o.stroke) {
    node.strokes = solidColor(o.stroke);
    node.strokeWeight = 1;
    node.strokeAlign = "INSIDE";
  }
  if (o.align) node.counterAxisAlignItems = o.align;
  if (o.justify) node.primaryAxisAlignItems = o.justify;
  return node;
}

// resize() pins BOTH axes to fixed. Use this to fix only the width and keep hugging the height.
function fixWidth(node, width) {
  node.resize(width, node.height);
  if (node.type === "TEXT") { node.textAutoResize = "HEIGHT"; return node; }
  node.layoutSizingHorizontal = "FIXED";
  if (node.layoutMode !== "NONE") node.layoutSizingVertical = "HUG";
  return node;
}

// Text inside a fixed-width container must wrap, or it runs past the edge.
// Call AFTER appendChild — FILL only works inside an auto-layout parent.
function wrap(textNode) {
  textNode.textAutoResize = "HEIGHT";
  textNode.layoutSizingHorizontal = "FILL";
  return textNode;
}

// Icons are drawn as shapes — glyphs like ☰ or ✕ are not in Inter and render as boxes
function iconMenu(hex, size = 24) {
  const icon = named(figma.createFrame(), "Icon/Menu");
  icon.resize(size, size);
  icon.fills = [];
  for (const y of [0.25, 0.5, 0.75]) {
    const bar = figma.createRectangle();
    bar.resize(size * 0.75, 2);
    bar.x = size * 0.125; bar.y = size * y - 1;
    bar.cornerRadius = 1;
    bar.fills = solidColor(hex);
    icon.appendChild(bar);
  }
  return icon;
}

// Runs one phase; a failure is logged and the next phase still runs
async function runPhase(label, fn) {
  try {
    await fn();
  } catch (err) {
    console.error(`❌ Phase "${label}" failed:`, err);
  }
}

// ---- FONTS ----
// Loads only the styles the tokens use. If a family can't be loaded, try its
// FONT_FALLBACKS, then Inter, and rewrite the typography tokens to what loaded —
// otherwise the failure only shows up later, when a text node is created.
async function tryLoadFamily(family, styles) {
  try {
    for (const style of styles) await figma.loadFontAsync({ family, style });
    return true;
  } catch {
    return false;
  }
}

async function loadFonts() {
  const typos = Object.values(tokens.typography);
  for (const family of [...new Set(typos.map(t => t.family))]) {
    const styles = [...new Set(["Regular", ...typos.filter(t => t.family === family).map(t => weightToStyle(t.weight))])];
    let used = null;
    for (const candidate of [family, ...(FONT_FALLBACKS[family] || []), "Inter"]) {
      if (await tryLoadFamily(candidate, styles)) { used = candidate; break; }
    }
    if (!used) throw new Error(`No font could be loaded for "${family}" (not even Inter)`);
    if (used !== family) {
      console.warn(`  Font "${family}" is not available in Figma — using "${used}"`);
      for (const t of typos) if (t.family === family) t.family = used;
    }
  }
}

// ---- CREATE TOKEN STYLES ----
async function createTokenStyles() {
  for (const [name, hex] of Object.entries(tokens.colors)) {
    const style = figma.createPaintStyle();
    style.name = `Colors/${name}`;
    style.paints = solidColor(hex);
  }
  for (const [name, props] of Object.entries(tokens.typography)) {
    const style = figma.createTextStyle();
    style.name = `Typography/${name}`;
    style.fontName = { family: props.family, style: weightToStyle(props.weight) };
    style.fontSize = props.size;
    // MULTIPLIER is invalid — convert to PERCENT (e.g. 1.5 → 150)
    const lhValue = props.lineHeight < 10 ? props.lineHeight * 100 : props.lineHeight;
    style.lineHeight = { unit: "PERCENT", value: lhValue };
  }
  for (const name of Object.keys(tokens.shadows)) {
    const style = figma.createEffectStyle();
    style.name = `Shadows/${name}`;
    style.effects = shadow(name);
  }
}

// ---- COMPONENT BUILDERS ----
// Each builder styles the node it is given: a component on the Components page, or a
// plain frame when a screen needs a state the component doesn't have (e.g. a header
// with a Back button). Every text layer gets a name so instances can override it.
function fillButton(node, { bg, fg, stroke, label = "Button" }) {
  autoLayout(node, "HORIZONTAL", { padX: 16, padY: 8, gap: 8, radius: 8, fill: bg, stroke, align: "CENTER", justify: "CENTER" });
  node.appendChild(named(txt(label, "button", fg), "Label"));
}

function fillCard(node, { title = "Card title", body = "A short line of sample text for this card.", width = 320 } = {}) {
  autoLayout(node, "VERTICAL", { padX: 24, padY: 24, gap: 12, radius: 12, fill: C["surface"], stroke: C["border"] });
  node.effects = shadow("card");
  fixWidth(node, width);
  // Photo placeholder uses a token that contrasts with the card fill
  const photo = named(figma.createRectangle(), "Photo");
  photo.resize(width - 48, 120);
  photo.cornerRadius = 8;
  photo.fills = solidColor(C["border"]);
  node.appendChild(photo);
  photo.layoutSizingHorizontal = "FILL";
  for (const [chars, typo, color, layer] of [
    [title, "heading-md", C["text-primary"], "Title"],
    [body, "body-sm", C["text-secondary"], "Body"],
  ]) {
    const t = named(txt(chars, typo, color), layer);
    node.appendChild(t);
    wrap(t);
  }
}

function fillInput(node, { value = "Placeholder", width = 280 } = {}) {
  autoLayout(node, "HORIZONTAL", { padX: 12, padY: 8, radius: 8, fill: C["background"], stroke: C["border"], align: "CENTER" });
  fixWidth(node, width);
  const t = named(txt(value, "body-base", C["text-secondary"]), "Value");
  node.appendChild(t);
  wrap(t);
}

function fillBadge(node, { bg, fg, label = "Badge" }) {
  autoLayout(node, "HORIZONTAL", { padX: 8, padY: 2, radius: 9999, fill: bg, align: "CENTER" });
  node.appendChild(named(txt(label, "caption", fg), "Label"));
}

// ---- COMPONENTS ----
// Claude Code fills this based on actual components found in repo.
// Each variant is its own component (Button ×3 + Badge ×3 = 6 entries, not 2).
const components = [
  { name: "Button/Primary",   build: n => fillButton(n, { bg: C["primary"], fg: C["text-inverse"] }) },
  { name: "Button/Secondary", build: n => fillButton(n, { bg: "transparent", fg: C["primary"], stroke: C["primary"] }) },
  { name: "Button/Ghost",     build: n => fillButton(n, { bg: "transparent", fg: C["text-secondary"] }) },
  { name: "Card/Default",     build: n => fillCard(n) },
  { name: "Input/Default",    build: n => fillInput(n) },
  { name: "Badge/Primary",    build: n => fillBadge(n, { bg: C["primary-subtle"], fg: C["primary"] }) },
  { name: "Badge/Success",    build: n => fillBadge(n, { bg: C["success-subtle"], fg: C["success"] }) },
  { name: "Badge/Error",      build: n => fillBadge(n, { bg: C["error-subtle"], fg: C["error"] }) }
];
const componentNodes = {};

// Instance with text overrides by layer name. Overriding text, font size and padding
// is allowed; adding children is not (Rule 11) — detach only as a last resort.
function instance(name, textOverrides = {}) {
  const main = componentNodes[name];
  if (!main) throw new Error(`Component "${name}" was not built`);
  const inst = main.createInstance();
  for (const [layer, value] of Object.entries(textOverrides)) {
    const t = inst.findOne(n => n.type === "TEXT" && n.name === layer);
    if (!t) throw new Error(`No text layer "${layer}" in ${name}`);
    t.characters = value;
  }
  return inst;
}

const pages = [

// ---- CREATE COMPONENTS ----
async function createComponents() {
  const page = figma.createPage();
  page.name = "🧩 Components";
  // Canvas color from a token so light-on-dark components stay visible
  page.backgrounds = solidColor(C["surface"]);
  await figma.setCurrentPageAsync(page);

  let x = 40;
  let built = 0;
  console.log(`  Building ${components.length} component(s)...`);
  for (const comp of components) {
    try {
      const node = figma.createComponent();
      node.name = comp.name;
      page.appendChild(node);
      comp.build(node);
      node.x = x;
      node.y = 40;
      componentNodes[comp.name] = node;
      x += node.width + 40;
      built++;
    } catch (err) {
      console.warn(`  ⚠️ Skipped component "${comp.name}": ${err.message || err}`);
    }
  }
  console.log(`  Built ${built}/${components.length} components`);
}

// ---- BUILD FRAMES ----
// One section inside a page frame. The page frame uses auto layout, so sections
// stack instead of overlapping; layoutSizing* must be set AFTER appendChild.
function buildSection(section, parent, size) {
  const layout = (size.label === "Mobile" && section.mobileLayout) || section.layout;
  const s = named(figma.createFrame(), section.name);
  s.fills = solidColor(section.bg || C["surface"]);
  if (layout) {
    autoLayout(s, layout, {
      gap: section.gap ?? 16, padX: section.paddingX ?? 16, padY: section.paddingY ?? 16,
      fill: section.bg || C["surface"], stroke: section.border,
      align: section.align, justify: section.justify,
    });
  }
  parent.appendChild(s);

  // resize() resets sizing to FIXED, so resize first and set FILL/HUG after
  if (section.width || section.height) s.resize(section.width || s.width, section.height || s.height);
  s.layoutSizingHorizontal = section.width ? "FIXED" : "FILL";
  if (section.height) s.layoutSizingVertical = "FIXED";
  // In a row, sections hug for now — buildFrames stretches them to FILL after the frame
  // gets its final height (FILL inside a hugging parent is unreliable)
  else if (layout) s.layoutSizingVertical = "HUG";

  if (section.build) section.build(s, size);
  return s;
}

// ALL frames on ONE page — never create a page per route (free plan = 3 pages max)
async function buildFrames() {
  const figmaPage = figma.createPage();
  figmaPage.name = "📐 Frames";
  await figma.setCurrentPageAsync(figmaPage);

  const GAP = 80;
  let xOff = 0;
  let built = 0;
  console.log(`  Building ${pages.length} page(s) × ${FRAME_SIZES.length} sizes (mobile + desktop)`);

  for (const pageData of pages) {
    let pageOk = true;
    // Mobile first, desktop 80px to the right (Rule 4)
    for (const size of FRAME_SIZES) {
      try {
        const frame = named(figma.createFrame(), `${pageData.name} – ${size.label} (${size.width})`);
        frame.fills = solidColor(pageData.bg || C["background"]);
        frame.clipsContent = true;
        frame.layoutMode = (size.label === "Mobile" && pageData.mobileLayout) || pageData.layout || "VERTICAL";
        figmaPage.appendChild(frame);
        frame.x = xOff; frame.y = 0;
        // Fixed device width, height hugs the content
        fixWidth(frame, size.width);

        const wanted = size.label.toLowerCase();
        for (const section of (pageData.sections || [])) {
          if (section.only && section.only !== wanted) continue;
          try {
            buildSection(section, frame, size);
          } catch (err) {
            console.warn(`    ⚠️ Skipped section "${section.name}" in ${frame.name}: ${err.message || err}`);
          }
        }

        // Final height = max(device, content), so tall pages are never clipped.
        // Then stretch row sections (e.g. Sidebar + Main) to that height.
        frame.resize(size.width, Math.max(size.height, frame.height));
        if (frame.layoutMode === "HORIZONTAL") {
          for (const child of frame.children) {
            if (child.layoutSizingVertical === "HUG") child.layoutSizingVertical = "FILL";
          }
        }
        console.log(`  ✓ Frame: ${frame.name}`);
      } catch (err) {
        pageOk = false;
        console.warn(`  ⚠️ Skipped frame "${pageData.name} – ${size.label}": ${err.message || err}`);
      }
      xOff += size.width + GAP;
    }
    if (pageOk) built++;
  }

  console.log(`  Built ${built}/${pages.length} pages`);
}

// ---- RUN EVERYTHING ----
// Top-level await — no IIFE wrapper (console crashes with async IIFE)
console.log('🚀 Design import starting...');
console.log('   Phases: fonts → token styles → components → frames');

await runPhase('Load Fonts', async () => {
  console.log('⏳ [1/4] Loading fonts...');
  await loadFonts();
  console.log('✅ [1/4] Fonts loaded');
});

await runPhase('Token Styles', async () => {
  console.log('⏳ [2/4] Creating token styles...');
  await createTokenStyles();
  console.log('✅ [2/4] Token styles created');
});

await runPhase('Components', async () => {
  console.log('⏳ [3/4] Building components...');
  await createComponents();
  console.log('✅ [3/4] Components built');
});

await runPhase('Frames', async () => {
  console.log('⏳ [4/4] Building frames...');
  await buildFrames();
  console.log('✅ [4/4] Frames built');
});

console.log('');
console.log('🎉 Import complete. Check each phase above for any partial failures.');
```

### Why the template is built this way (learned in real Figma)

| Pattern | Problem it prevents |
|---|---|
| `wrap(text)` after `appendChild` | Text defaults to auto-width and runs past the edge of cards and other fixed-width containers |
| `fixWidth(node, w)` instead of `resize()` | `resize()` pins **both** axes to fixed, so the height stops following the content |
| Resize first, then set `FILL`/`HUG` | `resize()` resets sizing back to fixed |
| Frames hug, then `resize(width, max(device, content))` | Fixed 844/960 heights clip long pages |
| Row sections stretched to `FILL` only after the final resize | `FILL` inside a parent that is still hugging is unreliable |
| Builder functions (`fillButton`, `fillCard`...) | Flat width/height entries only fit buttons and badges. The same builder also styles a plain frame when a screen needs a state the component doesn't have |
| Named text layers + `instance(name, { Layer: "text" })` | Instances allow text, font size and padding overrides, but not new children (Rule 11) |
| `loadFonts()` fallback chain | A font that fails to load only errors later, when a text node is created |
| Loading only the styles the tokens use | Families like Roboto have no "Semi Bold" — requiring every style would reject the whole family |
| `shadow()` + effect styles | box-shadow values were extracted but never drawn |
| `iconMenu()` shapes | Glyphs like ☰ and ✕ are not in Inter |
| `page.backgrounds` from a token | Light-on-dark components vanish on a white canvas |
| Photo placeholder uses `border`, not `surface` | A placeholder the same color as the card is invisible |
